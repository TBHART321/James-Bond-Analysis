Overview:

An analysis of all 25 James Bond films examining financial performance and critical reception to determine which Bond actor performed best across multiple metrics.

Tools used:

Microsoft Excel, Tableau Public

Data Sources:

Base dataset pulled from - https://www.kaggle.com/datasets/dreb87/jamesbond
I added the information for 'No Time to Die'
Additional information was pulled from sources like IMDB as well as google AI answers

Key Findings:

Sean Connery leads in average inflation-adjusted ROI per film. Daniel Craig leads in critical reception on both IMDb and Rotten Tomatoes. Roger Moore had the most films but the lowest critical scores. Timothy Dalton had the lowest financial performance of any Bond actor.

Skills Demonstrated:

Data collection and sourcing. Data cleaning and preparation in Excel. Inflation adjustment calculations. Summary table creation using COUNTIF, SUMIF, and AVERAGEIF formulas. Data visualization in Tableau.
